# Changelog

## 1.0.0 (October 2026)

First version.

- Today view with the class in progress, the next one, upcoming deadlines and the overall average.
- Grade calculator for 4 parciales (configurable) with a passing grade of 70, grades typed directly or built from activities, a personal goal per subject and the grade needed in the remaining parciales.
- Year summary: overall average, average per parcial and number of subjects passing.
- Letter grade and GPA equivalents (College Board scale) and an optional American system for bilingual schools.
- University section with terms, courses with credits (UV), global academic index, graduation index and GPA.
- Task list grouped by overdue, today, this week and later.
- Weekly class schedule with overlap warnings.
- Pomodoro timer based on timestamps, with sound, optional notifications and daily stats.
- Backup export and import, Spanish and English, light and dark mode.
- Installable PWA that works offline.
- Strict Content Security Policy with Trusted Types, validation of all stored and imported data, and 37 tests.
